### About me

I build the pipelines that turn raw operational data into decisions.

Day to day, I design and run **Azure data platforms** for enterprise clients — ingestion from business systems (NetSuite, Dynamics 365, SharePoint), modelling in SQL Server, and delivery through Power BI. I came to data engineering from **full-stack development**, and I've since specialised in **applied AI** on the Microsoft stack.

- 🏗️ Currently: end-to-end data platforms — Azure Data Factory, Azure Functions, SQL Server, Power BI
- 🔌 Focus areas: REST/OAuth 2.0 API integration, incremental ingestion patterns, Dataverse synchronisation
- ⚡ Also into: Power Query &amp; DAX performance tuning (recent win: a 4h refresh brought down to minutes)
- 🤖 Exploring: agentic AI, Copilot Studio, and LLM-assisted developer workflows
- 💬 Ask me about: ADF pipeline design, NetSuite SuiteQL extraction, Power BI modelling
